# DiceRoll
A simple Kotlin + Jetpack Compose dice roller. Tap the dice or button to roll with a spinning animation.

## Build requirements
Android SDK 35, JDK 17, and Gradle 8.7 compatible tooling. The ZIP does not include a Gradle wrapper; use the Gradle runtime supplied by your IDE or generate a wrapper. On-device Android IDEs may require additional SDK/toolchain configuration.
